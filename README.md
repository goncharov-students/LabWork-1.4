# LabWork-1.4
# Лабораторная работа 1.4: NumPy, описательная статистика, Bootstrap и проверка гипотез в аналитике данных

## Цель работы
Освоение базовых операций с массивами NumPy, расчёт и интерпретация описательных статистик, исследование влияния выбросов, применение Bootstrap для оценки неопределённости и проверка статистических гипотез.

## Задачи работы
- Освоить базовые операции с массивами NumPy
- Научиться выполнять векторизованную обработку и фильтрацию данных
- Рассчитывать и интерпретировать основные статистические характеристики
- Исследовать влияние выбросов на статистические показатели
- Использовать квантили и процентили для анализа качества сервиса
- Рассчитывать и интерпретировать коэффициент корреляции
- Оценивать неопределённость статистических оценок с помощью Bootstrap
- Формулировать статистические гипотезы и интерпретировать ошибки I и II рода
